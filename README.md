# 인력 현황 관리대장

1공장·2공장 일일 계획 대비 실제 인원(총원/휴가/퇴사/신규), 협력업체(성주/아웃소싱) 비중, 그리고
작업자 명단·출근 현황을 한 화면에서 관리하는 대장입니다.

## 파일

- `worker-status-ledger.html` — 관리대장 웹 앱(단일 HTML 파일, 별도 서버 없이 브라우저에서 바로 실행)

## 매일 최신 엑셀 자료로 갱신하는 방법

`2026-Factory_1_2_Manpower.xlsx`(HS / Sung Ju / Outsource 시트 기준)가 매일 갱신됩니다.
`worker-status-ledger.html`을 열고 우측 상단 **"엑셀 업로드"** 버튼으로 그날의 엑셀 파일을 선택하면:

- 계획 인력 표(1공장/2공장/전사 총원·휴가·퇴사·신규, 성주/아웃소싱 비중)가 날짜별로 갱신되고,
- 페이지를 열 때마다 **실제 데이터가 채워진 가장 최근 날짜**를 자동으로 "오늘"로 인식해 보여줍니다.
- 과거 날짜 데이터는 지워지지 않고 그대로 누적되므로, 매일 그날 파일만 업로드하면 됩니다.

브라우저 로컬 저장(localStorage)에도 남기 때문에 같은 브라우저에서 새로고침해도 유지됩니다.
여러 사람과 실시간으로 같은 화면을 공유하려면 이 파일을 Claude 아티팩트로 게시해서 쓰는 것을 권장합니다
(그 경우 업로드한 내용이 게시된 링크를 여는 모든 사람에게 자동으로 동기화됩니다).
