# 프로젝트 이름

기본 랜딩페이지 템플릿입니다.

## 구조

```
index.html      # 메인 페이지
css/style.css   # 스타일
js/main.js      # 스크립트
```

## 로컬에서 실행하기

별도 빌드 도구 없이 정적 파일이므로, `index.html`을 브라우저로 바로 열거나
아래처럼 간단한 로컬 서버로 실행할 수 있습니다.

```
python3 -m http.server
```

이후 `http://localhost:8000` 접속.
