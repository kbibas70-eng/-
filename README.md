# 인력 현황 관리대장

1공장·2공장 일일 계획 대비 실제 인원(총원/휴가/퇴사/신규), 협력업체(성주/아웃소싱) 비중, 그리고
작업자 명단·출근 현황을 한 화면에서 관리하는 대장입니다.

## 파일

- `worker-status-ledger.html` — 관리대장 웹 앱(단일 HTML 파일, 별도 서버 없이 브라우저에서 바로 실행)

## 매일 최신 엑셀 자료로 갱신하는 방법

`2026-Factory_1_2_Manpower.xlsx`(HS / Sung Ju / Outsource 시트 기준)가 매일 갱신됩니다.
`worker-status-ledger.html`을 열고 우측 상단 **"엑셀 업로드"** 버튼으로 그날의 엑셀 파일을 선택하면:

- 계획 인력 표(1공장/2공장/전사 총원·휴가·퇴사·신규, 성주/아웃소싱 비중)가 날짜별로 갱신되고,
- 페이지를 열 때마다 **실제 데이터가 채워진 가장 최근 날짜**를 자동으로 "오늘"로 인식해 보여줍니다.
- 과거 날짜 데이터는 지워지지 않고 그대로 누적되므로, 매일 그날 파일만 업로드하면 됩니다.

브라우저 로컬 저장(localStorage)에도 남기 때문에 같은 브라우저에서 새로고침해도 유지됩니다.
여러 사람과 실시간으로 같은 화면을 공유하려면 이 파일을 Claude 아티팩트로 게시해서 쓰는 것을 권장합니다
(그 경우 업로드한 내용이 게시된 링크를 여는 모든 사람에게 자동으로 동기화됩니다).

## 현재 데이터 상태

이번 초기 버전에는 2026-01-01 ~ 2026-12-31 계획치와 2026-09-16까지의 실제 실적이 담긴

# 자격증명 관리대장 (Certification Ledger)

작업자별 자격증명(공정 적합성 확인서, GIẤY CHỨNG NHẬN ĐỦ ĐIỀU KIỆN) 1인 1시트로 구성된
`CHỨNG CHỈ U1.xlsm`을 업로드해서, 작업자별 사진·부서·공정·교육이력을 한 화면에서 관리하는 대장입니다.

## 파일

- `certification-ledger.html` — 관리대장 웹 앱(단일 HTML 파일, 별도 서버 없이 브라우저에서 바로 실행)

## 엑셀 업로드 및 데이터 유지 방식

- 이 파일은 **처음 열면 항상 빈 화면**입니다(등록된 인원 0명). 우측 상단 **"엑셀 업로드"** 버튼으로
  `CHỨNG CHỈ U1.xlsm`(또는 같은 양식의 `.xlsx`)을 선택해야 그 안의 인원·사진·교육이력이 화면에 채워집니다.
- 업로드한 내용은 그 즉시 **로컬 저장(IndexedDB)**에 저장되므로, 창을 껐다가 다시 열거나
  새로고침해도 업로드한 내용이 그대로 유지됩니다(같은 컴퓨터·같은 브라우저 기준). 사진이 많이 포함된
  데이터도 안정적으로 저장되도록, 용량 제한이 작은 `localStorage` 대신 `IndexedDB`를 사용합니다.
- 최신 엑셀 파일로 다시 갱신하고 싶을 때는 같은 **"엑셀 업로드"** 버튼으로 새 `.xlsm`/`.xlsx` 파일을
  선택하면 사번 기준으로 신규/변경분만 반영되고, 현장에서 직접 입력한 서명·수기 교육이력은 지워지지 않습니다.
- 우측 상단 **"초기화"** 버튼을 누르면 이 컴퓨터·브라우저에 저장된 데이터를 모두 지우고
  다시 빈 화면(엑셀 업로드 전 상태)으로 돌아갑니다 — 엑셀 파일 자체가 지워지는 것은 아니므로
  같은 파일을 다시 업로드하면 됩니다.
- 데이터를 백업하려면 **"백업 내보내기"**로 JSON 파일을 받아두고, 필요할 때 **"백업 불러오기"**로 복원할 수 있습니다.
